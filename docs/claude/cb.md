# 可轉債（`/cb`）

> 什麼時候讀：改可轉債頁、`scripts/fetch_cb.py`、`app/src/lib/cb.ts`。

2026-11-04 使用者要求：獨立一頁、每天更新。要看的東西：價格區間分布與累計比例、平均價／PR75／PR90、
平均轉換價值與溢價率（格式照使用者給的 XQ 看板截圖）、價格 120～150 與 ≥150 的比例、目前價格、
待發行、發行公司依產業整理（看是不是同產業集中發債）、點可轉債可看公司近期新聞與營收。

## 資料：`fetch_cb.py` → `cb.json`（不進版控，deploy.yml 產生）

| 來源 | 內容 |
| --- | --- |
| 櫃買 `storage/bond_zone/tradeinfo/cb/YYYY/YYYYMM/RSta0113.YYYYMMDD-C.csv` | 買賣斷交易行情表：收市、漲跌、成交張數與金額、明日參價 |
| 櫃買 `…/RSdrs001.YYYYMMDD-C.csv` | 轉換公司債資訊看板：轉換價、生效日、賣回、強制贖回、原始發行額、上月底餘額、標的股價 |
| 櫃買 OpenAPI `bond_ISSBD5_data` | 轉(交)換債發行資料：發行日、到期日、擔保；**待發行**也從這裡來 |
| 證交所 `STOCK_DAY_ALL`、櫃買 `tpex_mainboard_daily_close_quotes` | 標的股票當天收盤 |
| `fin_history.json` 的 `info` | 公司名稱、產業 |

兩份 CSV 是櫃買「轉(交)換債日統計報表」頁的下載檔；那頁用 `POST /www/zh-tw/bond/cbDaily`
（`fileCode=rsta0113`／`cbdrs001`）列出檔名，但路徑規則固定，所以直接組網址、往回找最近一份。
檔案是 **cp950**；行情表每檔兩列（等價、議價），只取等價。**資訊看板比行情晚一天**（傍晚只有前一交易日）。

## 口徑（畫面上都寫了）

- **價格**：有成交用收市價，沒成交用參考價。XQ 看板用**委買價**，官方免費資料沒有，所以兩邊的
  區間檔數不會一樣。冷門債的參考價可能好幾天沒動 —— 看板有「只算今天有成交」切換。
- 轉換價值 ＝ 100 × 股價 ÷ 轉換價；溢價率 ＝ 價格 ÷ 轉換價值 − 1。PR75／PR90 是 PERCENTILE.INC（線性內插）。
- 看板的轉換價是**下次生效日之後**的（櫃買註 2），生效日存在 `cpEff`。
- 交換債（代號 6 碼、名稱帶 E，標的不是代號前四碼）：今天收盤與看板的標的股價差 > 15% 時改用看板股價，標 `exch`。
- 待發行：公開募集（`OfferingMethod=7`）且發行日或上櫃日在行情日之後。私募（`=8`）不在櫃買交易，不列。
  董事會決議、申報中的還沒有 BondCode，也不會在這份資料裡。
- 產業整理：近 180 天新發行＋待發行多的排前面。

## 點一檔之後

開個股抽屜（`StockSheet`，營收、財報、籌碼都在裡面），`extra` 放這一檔債的細節與 `news.json`
裡掛到這家公司的新聞與重大訊息（只有最近幾天），另附鉅亨網與觀測站的外連。新聞只在點開時才抓。
